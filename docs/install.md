# 安裝

先到 [Releases](https://github.com/markleetw/reverse-due-diligence-skill/releases) 下載最新的 `reverse-due-diligence.zip`。

## Claude

1. 打開 **自訂 → 技能**
2. 點 **+ → 建立技能 → 上傳技能**
3. 選擇 `reverse-due-diligence.zip`
4. 開啟這個 Skill

## ChatGPT

1. 打開 **自訂 → 技能**
2. 查看「新增」選單
3. 如果有 **從電腦上傳**，選擇 `reverse-due-diligence.zip`

如果「新增」裡沒有 **從電腦上傳**，目前就無法從 Release 直接安裝這個 Skill。

> 不要從「外掛程式」的上傳入口安裝，兩者格式不同。

## 開始使用

```text
/rdd 台積電 資深工程師
```

也可以直接說：

```text
我正在面試某家公司 Head of Product，幫我做反向盡調。
```
