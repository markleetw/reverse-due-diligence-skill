# 台灣公司的資料管道

依「拿得到什麼」排序，不是依知名度。上市／上櫃公司有法定揭露，資料量遠大於未上市公司。

## 一、財務數字

| 來源 | 拿得到什麼 | 備註 |
|---|---|---|
| **公開資訊觀測站 mops.twse.com.tw** | 年報、財報、重大訊息、股東會議事錄、董監持股、**員工人數與薪資揭露** | 最權威。年報附註是唯一能查到應收款明細、備抵損失、關係人交易的地方 |
| **財報狗 statementdog.com/analysis/{代號}** | 損益表、資產負債表、成長率、關鍵比率 | 部分需付費；免費頁仍可拿到近四季 |
| **Yahoo 股市 tw.stock.yahoo.com/quote/{代號}.TW/** | `/revenue` 月營收、`/income-statement`、`/balance-sheet`、`/eps`、`/major-holders` | 免費且好抓，優先用 |
| **HiStock histock.tw/stock/{代號}/每股盈餘** | 歷年與各季 EPS | 補 Yahoo 的歷史深度 |
| **Goodinfo** | 歷年經營績效、股利政策 | robots.txt 常擋，未必抓得到 |
| **玩股網 wantgoo.com/stock/{代號}** | 即時股價、市值、本益比、股價淨值比、52 週區間 | |
| **nStock、優分析、Win 投資** | 產業分類、同業比較、白話拆解 | 交叉驗證用 |

## 二、法說會與經營層說法

- **富果直送 blog.fugle.tw/post/earnings-call-{代號}-{YYYYMMDD}** — 台股法說會逐場紀要，**細節密度最高的免費來源**，常有單一產品線的絕對金額與逾期率之類的數字，媒體報導通常不會寫
- 公司官網投資人關係頁的法說會簡報 PDF
- **MoneyDJ、鉅亨網、經濟日報、工商時報** — 法說會後的即時報導
- **數位時代 bnext.com.tw、INSIDE、iThome、科技新報** — 深度訪談與策略分析；iThome 的人物專訪常談到技術架構與組織運作方式

## 三、股權與公司登記

- **公開資訊觀測站** — 董監事持股、持股逾 10% 大股東、股權變動申報
- **Yahoo 股市 /major-holders** — 外資比例、董監持股比例
- **TechNews 公司資料庫 info.technews.tw/company/{統編}** — 董監名單、代表法人、持股數、資本額、營業項目
- **經濟部商業司商工登記公示資料查詢** — 未上市公司唯一的官方管道
- **企業登記查詢站（如 twincn、find.taipei）** — 統編、負責人、變更歷程

## 四、薪酬（依可信度排序）

1. **公開資訊觀測站「非主管職務之全時員工薪資資訊」** — 上市櫃公司法定揭露，含**全體員工平均薪資**與**非主管員工薪資中位數**。這是談薪最好的錨點
2. **104、Cake、Yourator 的職缺開價** — 有區間就是真的
3. **比薪水 salary.tw、面試趣 interview.tw、GetCareers** — 自填，樣本小且偏基層，只能當參考

## 五、文化與風評

- **面試趣 interview.tw/c/{id}/info** — 分構面評分（升遷、溝通、員工發展、性別友善、生活平衡）、面試流程、錄取率、平均年資
- **GoodJob 職場透明化運動 goodjob.life** — 工時統計、面試心得、勞動檢查紀錄
- **比薪水 salary.tw** — 員工短評，偶爾有一針見血的一句話
- **PTT**（Soft_Job、Tech_Job、MobileComm、Salary 板）— 用 `site:ptt.cc 公司名` 搜；產品爭議串常在產品對應的板
- **Dcard**（工作、理財、科技板）— 注意 `@brand_selection` 之類的帳號是業配，與使用者自發貼文要分開看
- **Glassdoor** — 台灣公司樣本通常很少，但外商台灣分公司值得查
- **vocus、Medium** — 面試心得長文，常有最完整的關卡拆解

## 六、監管與法遵（有金融、醫療、資料、平台業務時必查）

- **金管會、經濟部、數發部、公平會** 的新聞稿與裁罰紀錄
- **《報導者》twreporter.org** — 監管缺口的調查報導品質最高
- **法律百科 legis-pedia.com、PwC / KPMG / 資誠 的法規快訊** — 查法定上限與修法時程
- **司法院裁判書查詢系統** — 查公司或同業是否有相關判決
- 同結構在**日本、韓國、新加坡、歐盟**的監理見解——成熟市場常領先台灣三到五年

## 七、職缺本身

- **公司自己的徵才頁**（Lever `jobs.lever.co/{公司}`、Greenhouse、Ashby）— 列出**全部**開放職缺，可看出招募節奏、部門權重、是否在擴張或凍結
- 職缺原文裡的匯報對象、團隊規模、必要條件，是唯一直接描述該角色的一手資料
