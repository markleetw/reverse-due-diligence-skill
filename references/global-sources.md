# 外商與海外實體的資料管道

遇到外商台灣分公司、海外母公司或跨國集團時，把台灣管道換成以下對應來源。

## 財務與揭露

| 情境 | 來源 |
|---|---|
| 美國上市 | **SEC EDGAR**（10-K、10-Q、8-K、S-1、DEF 14A）。10-K 的 Risk Factors 與 MD&A 是金礦 |
| 日本上市 | **EDINET**、有価証券報告書；公司 IR 頁的決算説明会資料 |
| 韓國上市 | **DART (dart.fss.or.kr)** |
| 香港上市 | **HKEX 披露易** |
| 新加坡 | **SGXNet**、**ACRA** 公司登記 |
| 英國 | **Companies House**（含未上市公司的年度財報，資料意外地完整） |
| 歐盟 | 各國商業登記；上市公司看 annual report |
| 未上市新創 | **Crunchbase、PitchBook、Tracxn、CB Insights** — 募資輪次、投資人、估值 |

## 文化與薪酬

- **Glassdoor** — 評分、面試心得、薪資；注意公司可能有清理負評的動機
- **Blind (teamblind.com)** — 需公司信箱驗證，科技業覆蓋率高；內容常直接但仍屬匿名／半匿名訊號，需看樣本與交叉驗證
- **levels.fyi** — 科技業薪酬結構（base / stock / bonus）的重要參考來源之一；先對齊 role、level、location、年份與 total compensation 口徑
- **Indeed、Comparably、RepVue**（RepVue 專攻業務組織）
- **Reddit**（r/cscareerquestions、產業專版）、**Hacker News** 的 "Who is hiring" 與公司討論串
- **LinkedIn** — 員工人數趨勢、離職率觀察（看該公司員工的異動密度）、可聯繫的前員工

## 新聞與分析

- **The Information、Business Insider、TechCrunch、Bloomberg、Reuters、FT**
- **Seeking Alpha、Motley Fool** — 散戶視角的多空論述，適合快速抓爭議點
- 產業分析師報告（多半付費，但摘要常被媒體引用）

## 監管

- 各國主管機關（SEC、FTC、FCA、BaFin、金融庁、公取委、EU Commission）
- 集體訴訟資料庫、消費者保護機關的警示公告

## 判斷準則

外商台灣分公司要**分開查兩層**：

1. **全球母公司**的財務、策略與裁員紀錄——決定台灣分公司的資源與存續
2. **台灣分公司**的實際規模、決策權限與匯報線——決定這個角色是不是「執行單位」

最常見的落差是：母公司財報漂亮，但台灣是成本中心，產品決策全在總部。**這一點會徹底改變「Head of Product」這種 title 的實質含意**，必須查清楚並在報告裡點明。
